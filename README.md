# Paul — Portfolio

موقعي الشخصي (بورتفوليو) — صفحة ثابتة بالعربي.

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
```

## النشر على Vercel

المشروع موقع ثابت (static) — اربط الريبو بـ Vercel وهيتنشر تلقائيًا.
